# Attestation

Copy this into the description of your pull request and fill it in. The lines marked *person* are yours to write; an
assistant may fill in the lines marked *facts*.

```
Contribution: [run | re-performance | review | domain]

Person
- Name or handle to credit:                                  (person)
- Relationship to the maintainer or to PANGUARD AI, INC.:    (person; "none" if none)
- Interests a reader should know (employer sells a related
  product, the agent tested is mine, and so on):             (person)

Assistant
- Tool and model that helped, if any:                        (facts)
- What it did:                                               (facts)

What I checked myself                                        (person)
- [ ] I read every file in this pull request.
- [ ] The parts the card marks as mine are my own answers.
- [ ] Nothing here is real personal, customer or credential data.
- Anything I did not check, and why:

Checks                                                       (facts)
- Commands run and their last lines:
- Digest of the receipt or record this is based on, if any:
```

A pull request without this stays a draft.
